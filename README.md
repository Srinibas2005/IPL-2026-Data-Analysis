# IPL-2026-Data-Analysis
# 🏏 IPL Data Analysis using Python

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on IPL ball-by-ball data to uncover scoring patterns, wicket trends, and team performance across different phases of an innings.

The analysis was carried out using Python and popular data analysis and visualization libraries.

---

## 🎯 Objectives

- Analyze run-scoring patterns across overs.
- Study wicket distribution by dismissal type.
- Compare team performances.
- Analyze Powerplay, Middle Overs, and Death Overs scoring.
- Generate meaningful insights through visualizations.

---

## 🛠️ Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

---

## 📊 Analysis Performed

### 1. Run Distribution Analysis
- Total runs scored by teams.
- Over-wise scoring trends.
- Phase-wise scoring comparison.

### 2. Wicket Analysis
- Distribution of wicket types.
- Most common dismissal methods.
- Wicket trends across innings.

### 3. Team Performance Analysis
- Team-wise total runs.
- Team-wise phase performance.
- Comparative analysis between teams.

### 4. Over Phase Analysis
Overs were categorized into:

| Phase | Overs |
|---------|---------|
| Powerplay | 1 - 6 |
| Middle Overs | 7 - 15 |
| Death Overs | 16 - 20 |

Analysis was performed to determine which teams perform best in each phase.

---

## 📈 Key Insights
- Certain teams consistently dominate Powerplay scoring.
- Caught dismissals are among the most common wicket types.
- Team scoring patterns vary considerably across innings phases.
- Middle overs often act as the foundation for strong finishing totals.
